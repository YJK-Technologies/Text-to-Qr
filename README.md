# QR Studio — React app without Vite

This version uses **Create React App (`react-scripts`)**, not Vite.

## Requirements
- Node.js and npm installed

## Run
```bash
npm install
npm start
```
The app opens at `http://localhost:3000`.

## Production build
```bash
npm run build
```
The deployable static output is created in the `build/` folder.

## Included features
- Live text/URL QR code preview
- Foreground/background color customization
- Adjustable output size and error correction
- PNG, JPEG, SVG, and PDF downloads
- Responsive UI
- Browser-side QR generation; no backend required
